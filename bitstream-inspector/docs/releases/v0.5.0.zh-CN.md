# Bitstream Inspector 0.5.0

[English](v0.5.0.md) | 简体中文

Windows 10/11 x86-64，按用户安装，无需管理员权限。

## 新增内容

- **质量 GUI**：加载参考 YUV，在后台逐帧计算 PSNR、SSIM、MSE、MSAD，提供质量
  图表、参考差异视图和 CSV 导出。
- **码流对比**：按显示顺序/POC/时间同步；并排、相减、温度图、PSNR 裁剪、
  水平分割、垂直分割视图；最多四路码流按 2x2 网格对比。
- **YUV 工具**：独立 YUV 查看器（矩阵/范围控制，可打开第二个文件做并排或差异
  比较并显示 PSNR/SSIM）；`yuvcmp` CLI 比较两个 raw planar YUV 文件；帧导出
  支持原生格式以及 I420/I422/I444/P010/P210。
- **HDR**：HDR10+（SMPTE ST 2094-40）识别与完整动态元数据（窗口、目标显示
  亮度、maxscl、平均 maxRGB、分位数、tone mapping、饱和度）；帧 CSV 增加
  逐帧 HDR10+ 列，状态栏显示摘要；`bsinfo --hdr` 和合规报告增加 HDR 元数据
  一致性检查。
- **分析**：MSE/MSAD 质量指标、码率图表 1/2/5 秒窗口、Y/Cb/Cr 单分量显示。

## 安装

1. 下载 `BitstreamInspector-0.5.0-win64-setup.exe`（或便携版
   `BitstreamInspector-0.5.0-win64-portable.zip`）。
2. 运行安装器。按用户安装到
   `%LOCALAPPDATA%\Programs\BitstreamInspector`，无需管理员/UAC。便携 ZIP
   可解压到任意目录。
3. 从开始菜单或可选的桌面快捷方式启动。
4. 通过 **Language / 语言** 随时切换界面语言。

静默安装：`BitstreamInspector-0.5.0-win64-setup.exe /S`
自定义目录：最后一个参数加 `/D=C:\path`（路径不能含空格）。

从 **设置 → 应用 → 已安装的应用 → Bitstream Inspector** 卸载。卸载器会询问
是否保留 `%APPDATA%\BitstreamInspector` 设置。

## 验证

发布要求以下 job 全部通过：

- Linux x64/arm64：单元测试；覆盖 SEI/HDR、HDR10+ 动态元数据、HRD/CPB、
  参考列表、比特分配、slice/tile 叠加、MPEG-TS、PSNR/SSIM、MSE/MSAD、YUV
  比较与格式转换、AVI/FLV/MXF 的解析/解码回归；解码帧和 YUV 平面与 FFmpeg
  对比；ASan/UBSan 和变异 fuzz。
- MSVC：GUI、CLI 和单元测试编译通过，单元测试通过。
- Windows：交叉构建 GUI、CLI、安装包和便携 ZIP；原生运行
  `bsinfo.exe`/`mtest.exe`；GUI 启动、语言切换、缩略图窗口创建、便携 ZIP
  解压、安装/卸载往返。
- 覆盖率：插桩构建运行测试并上传报告。

## 已知限制

- 内置 FFmpeg 构建未启用 HEIC 和 MPEG-1 System 容器；未实现 VQM/NQI/VMAF。
- 多路对比窗口中差异指标只作用于前两路，附加码流显示正常画面。
- 安装包未签名；首次运行可能触发 SmartScreen 提示。
