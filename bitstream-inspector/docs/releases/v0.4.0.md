# Bitstream Inspector 0.4.0

English | [简体中文](v0.4.0.zh-CN.md)

Windows 10/11 x86-64, per-user installer, no administrator rights required.

## What's new

- **SEI and HDR**: H.264/H.265 MDCV, CLL, ATC, recovery point and T.35
  parsing; corrected payload names; HDR10/HLG summaries; H.265 prefix/suffix
  SEI support.
- **HRD and CPB**: H.264 VUI and H.265 VPS/SPS HRD storage,
  `buffering_period`/`pic_timing`, a CPB0 occupancy model with CBR/VBR,
  underflow/overflow, a chart mode and CSV/CLI output.
- **YUV tools**: native YUV plane decoding/export, a Y/Cb/Cr/RGB pixel probe,
  preview-only BT.601/709/2020 and limited/full controls, WIC PNG/BMP export
  and current-frame planar YUV export.
- **Navigation**: lazy thumbnail strip with GOP boundaries, previous/next GOP,
  exact raw-ES frame display including B pictures, and a Refs tab with L0/L1
  POCs, DPB counts and missing-reference warnings.
- **Quality and analysis**: PSNR/SSIM against a reference YUV (matching ffmpeg
  psnr/ssim), per-AU bit allocation and window bitrate, slice/CTB/tile
  overlay, a standalone MPEG-TS scanner, and Annex A conformance checks.
- **CLI and containers**: `bsinfo --json/--batch`, `mtest --ref/--range`, AVI,
  FLV, MXF and MPEG-PS demuxing, and a basic side-by-side Compare Streams
  window.

## Install

1. Download `BitstreamInspector-0.4.0-win64-setup.exe` (or the portable
   `BitstreamInspector-0.4.0-win64-portable.zip`).
2. Run the installer. It is per-user, installs to
   `%LOCALAPPDATA%\Programs\BitstreamInspector` and needs no admin/UAC. The
   portable ZIP can be extracted anywhere.
3. Start the application from the Start Menu or the optional desktop shortcut.
4. Switch the application language from **Language / 语言** at any time.

Silent install: `BitstreamInspector-0.4.0-win64-setup.exe /S`
Custom directory: add `/D=C:\path` as the last argument (path without spaces).

Uninstall from **Settings → Apps → Installed apps → Bitstream Inspector**.
The uninstaller asks whether to keep `%APPDATA%\BitstreamInspector` settings.

## Verification

Publishing this release required the following jobs to pass:

- Linux x64 and arm64: unit tests; parser/decode regression suite covering
  SEI/HDR, HRD/CPB, reference lists, bit allocation, slice/tile overlay,
  MPEG-TS, PSNR/SSIM, AVI/FLV/MXF; decoded frames and YUV planes compared with
  FFmpeg; ASan/UBSan and mutation fuzz.
- MSVC: GUI, CLI and unit tests compile and the unit tests pass.
- Windows: cross-build of the GUI, CLI, installer and portable ZIP; native
  execution of `bsinfo.exe`/`mtest.exe`; GUI startup, language switching,
  thumbnail-strip window creation, portable ZIP extraction, installer and
  uninstaller round trip.
- Coverage: the instrumented build runs the suite and uploads the report.

## Known limitations

- The GUI quality chart/difference view and POC/time-bound comparison modes
  are not implemented; PSNR/SSIM and TS analysis are CLI-first.
- GUI YUV range export is current-frame only; use `mtest --range` for ranges.
- H.265 tile layout is implemented but the local x265 build did not produce a
  tile test vector; IVF/MPEG-PS are demuxer-only coverage.
- The installer is unsigned; SmartScreen may ask for confirmation on first run.
