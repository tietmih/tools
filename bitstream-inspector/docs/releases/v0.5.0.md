# Bitstream Inspector 0.5.0

English | [简体中文](v0.5.0.zh-CN.md)

Windows 10/11 x86-64, per-user installer, no administrator rights required.

## What's new

- **Quality GUI**: load a reference YUV and get per-frame PSNR, SSIM, MSE and
  MSAD in a background worker, with a quality chart, a reference difference
  view and CSV export.
- **Compare Streams**: display-order/POC/time synchronization and
  side-by-side, subtraction, temperature, PSNR-clip, horizontal-split and
  vertical-split views; up to four streams can be compared in a 2x2 grid.
- **YUV tools**: a standalone YUV Viewer with matrix/range controls and an
  optional second input for side-by-side or difference comparison with
  PSNR/SSIM, plus a `yuvcmp` CLI for two raw planar YUV files. Frame export
  supports the native layout or I420/I422/I444/P010/P210.
- **HDR**: HDR10+ (SMPTE ST 2094-40) identification and full dynamic metadata
  (windows, targeted display luminance, maxscl, average maxRGB, percentiles,
  tone mapping, saturation), per-frame CSV columns and a status-bar summary;
  HDR metadata consistency checks in `bsinfo --hdr` and the conformance
  report.
- **Analysis**: MSE/MSAD quality metrics, selectable 1/2/5-second bitrate
  windows, and Y/Cb/Cr single-component display.

## Install

1. Download `BitstreamInspector-0.5.0-win64-setup.exe` (or the portable
   `BitstreamInspector-0.5.0-win64-portable.zip`).
2. Run the installer. It is per-user, installs to
   `%LOCALAPPDATA%\Programs\BitstreamInspector` and needs no admin/UAC. The
   portable ZIP can be extracted anywhere.
3. Start the application from the Start Menu or the optional desktop shortcut.
4. Switch the application language from **Language / 语言** at any time.

Silent install: `BitstreamInspector-0.5.0-win64-setup.exe /S`
Custom directory: add `/D=C:\path` as the last argument (path without spaces).

Uninstall from **Settings → Apps → Installed apps → Bitstream Inspector**.
The uninstaller asks whether to keep `%APPDATA%\BitstreamInspector` settings.

## Verification

Publishing this release required the following jobs to pass:

- Linux x64 and arm64: unit tests; parser/decode regression suite covering
  SEI/HDR, HDR10+ dynamic metadata, HRD/CPB, reference lists, bit allocation,
  slice/tile overlay, MPEG-TS, PSNR/SSIM, MSE/MSAD, YUV comparison and
  conversion, AVI/FLV/MXF; decoded frames and YUV planes compared with FFmpeg;
  ASan/UBSan and mutation fuzz.
- MSVC: GUI, CLI and unit tests compile and the unit tests pass.
- Windows: cross-build of the GUI, CLI, installer and portable ZIP; native
  execution of `bsinfo.exe`/`mtest.exe`; GUI startup, language switching,
  thumbnail-strip window creation, portable ZIP extraction, installer and
  uninstaller round trip.
- Coverage: the instrumented build runs the suite and uploads the report.

## Known limitations

- The bundled FFmpeg build does not enable HEIC or MPEG-1 System containers;
  VQM/NQI/VMAF metrics are not implemented.
- Difference metrics in the multi-stream compare window apply to the first two
  streams; the additional streams show normal pictures.
- The installer is unsigned; SmartScreen may ask for confirmation on first run.
