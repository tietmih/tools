# Bitstream Inspector 0.3.0

English | [简体中文](v0.3.0.zh-CN.md)

Bilingual release. Windows 10/11 x86-64, per-user installer, no administrator
rights required.

## What's new

- **Bilingual UI**: switch between English and Simplified Chinese at runtime
  from the **Language** menu. The choice is saved in
  `%APPDATA%\BitstreamInspector\settings.ini` and restored on the next start.
  Specification terms (NAL types, SPS/PPS/VPS, syntax field names,
  codec/profile names) stay in English in both UI languages.
- **Bilingual documentation**: README, changelog, screenshot notes and release
  notes now exist in English and Simplified Chinese, with language-switch links.
- **Bilingual installer**: the NSIS installer offers English / 简体中文 at
  startup, localizes its pages and includes both READMEs and both FFmpeg
  build-info files. The license page contains the English legal text plus a
  Chinese explanation.
- Chinese-aware frame-list column widths.
- Direct-DC fallback for the chart and hex views when PrintWindow supplies a DC
  without a compatible bitmap.

## Install

1. Download `BitstreamInspector-0.3.0-win64-setup.exe`.
2. Run it. The installer is per-user, installs to
   `%LOCALAPPDATA%\Programs\BitstreamInspector` and needs no admin/UAC.
3. Choose the installer language, then start the app from the Start Menu or the
   optional desktop shortcut.
4. Switch the application language from **语言 / Language** at any time.

Silent install: `BitstreamInspector-0.3.0-win64-setup.exe /S`
Custom directory: add `/D=C:\path` as the last argument (path without spaces).

Uninstall from **Settings → Apps → Installed apps → Bitstream Inspector**.
The uninstaller asks whether to keep `%APPDATA%\BitstreamInspector` settings.

## Verification

- Runtime Chinese/English switch and persistence across restart verified on
  Windows.
- Installer: silent install, launch of the installed app and silent uninstall
  verified, including shortcuts and the uninstall-registry entry. The installed
  file set includes both READMEs and both FFmpeg build-info files.
- Parser/decoder regression remains clean: frame counts and types vs `ffprobe`;
  fields vs FFmpeg `trace_headers`; PSNR = inf for real MP4/TS/MKV inputs;
  ASan/UBSan and mutation fuzz.
- UI strings were checked in both languages; the exact column widths were
  adjusted for Chinese headers.

## Known limitations

- Raw elementary streams carry no timestamps; the Video tab shows the nearest
  keyframe (labelled) instead of the exact frame.
- No thumbnail strip, slice/CTU overlays, DPB/GOP graph, HRD/CPB analysis or
  macroblock-level entropy decoding yet.
- Decoding is single-threaded per request.
- Container inputs report `Offset` in the reconstructed Annex B stream, not in
  the container file.
- The installer is unsigned; SmartScreen may ask for confirmation on first run.
