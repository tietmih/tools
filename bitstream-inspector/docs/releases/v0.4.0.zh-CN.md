# Bitstream Inspector 0.4.0

[English](v0.4.0.md) | 简体中文

Windows 10/11 x86-64，按用户安装，无需管理员权限。

## 新增内容

- **SEI 与 HDR**：H.264/H.265 的 MDCV、CLL、ATC、recovery point 和 T.35
  解析；修正 payload 名称；HDR10/HLG 摘要；H.265 prefix/suffix SEI。
- **HRD 与 CPB**：H.264 VUI 和 H.265 VPS/SPS HRD 入库，
  `buffering_period`/`pic_timing`，带 CBR/VBR 的 CPB0 占用模型、
  underflow/overflow、图表和 CSV/CLI 输出。
- **YUV 工具**：原生 YUV 平面解码/导出、Y/Cb/Cr/RGB 像素探针、仅预览生效的
  BT.601/709/2020 与 limited/full 控制、WIC PNG/BMP 和当前帧 planar YUV
  导出。
- **导航**：懒加载缩略图条和 GOP 边界、上一个/下一个 GOP、裸流精确帧
  （含 B 帧），以及带 L0/L1 POC、DPB 计数和缺失参考警告的 Refs 标签页。
- **质量与分析**：参考 YUV 的 PSNR/SSIM（与 ffmpeg psnr/ssim 一致）、
  逐 AU 比特分配和窗口码率、slice/CTB/tile 叠加、独立 MPEG-TS 扫描和
  Annex A 合规检查。
- **CLI 与容器**：`bsinfo --json/--batch`、`mtest --ref/--range`，AVI、
  FLV、MXF、MPEG-PS 解封装，以及基础并排 Compare Streams 窗口。

## 安装

1. 下载 `BitstreamInspector-0.4.0-win64-setup.exe`（或便携版
   `BitstreamInspector-0.4.0-win64-portable.zip`）。
2. 运行安装器。按用户安装到
   `%LOCALAPPDATA%\Programs\BitstreamInspector`，无需管理员/UAC。便携 ZIP
   可解压到任意目录。
3. 从开始菜单或可选的桌面快捷方式启动。
4. 通过 **Language / 语言** 随时切换界面语言。

静默安装：`BitstreamInspector-0.4.0-win64-setup.exe /S`
自定义目录：最后一个参数加 `/D=C:\path`（路径不能含空格）。

从 **设置 → 应用 → 已安装的应用 → Bitstream Inspector** 卸载。卸载器会询问
是否保留 `%APPDATA%\BitstreamInspector` 设置。

## 验证

发布要求以下 job 全部通过：

- Linux x64/arm64：单元测试；覆盖 SEI/HDR、HRD/CPB、参考列表、比特分配、
  slice/tile 叠加、MPEG-TS、PSNR/SSIM、AVI/FLV/MXF 的解析/解码回归；解码帧
  和 YUV 平面与 FFmpeg 对比；ASan/UBSan 和变异 fuzz。
- MSVC：GUI、CLI 和单元测试编译通过，单元测试通过。
- Windows：交叉构建 GUI、CLI、安装包和便携 ZIP；原生运行
  `bsinfo.exe`/`mtest.exe`；GUI 启动、语言切换、缩略图窗口创建、便携 ZIP
  解压、安装/卸载往返。
- 覆盖率：插桩构建运行测试并上传报告。

## 已知限制

- GUI 质量曲线/差异视图和 POC/时间绑定对比尚未实现；PSNR/SSIM 和 TS 分析
  以 CLI 为主。
- GUI YUV 范围导出只支持当前帧；范围导出请用 `mtest --range`。
- H.265 tile 布局已实现，但当前 x265 构建未生成 tile 测试向量；IVF/MPEG-PS
  只有 demuxer 覆盖。
- 安装包未签名；首次运行可能触发 SmartScreen 提示。
