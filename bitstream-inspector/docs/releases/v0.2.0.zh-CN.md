# Bitstream Inspector 0.2.0

[English](v0.2.0.md) | 简体中文

首个打包发布版本。Windows 10/11 x86-64，按用户安装，不需要管理员权限。

## 亮点

- H.264/H.265 分析器：帧列表、语法树、十六进制视图、码率图和解码画面预览。
- 支持 Annex B 裸流，**以及** MP4/MOV、MPEG-TS/M2TS、Matroska/WebM 容器。
- 容器输入按 PTS 精确解码选中帧；后台解码；十六进制/画面标签页。
- 可拖拽分栏、关键帧跳转、CSV 导出和布局持久化。
- 应用图标和 0.2.0 版本信息。

## 安装

1. 下载 `BitstreamInspector-0.2.0-win64-setup.exe`。
2. 运行安装包。按用户安装到
   `%LOCALAPPDATA%\Programs\BitstreamInspector`，不需要管理员权限或 UAC。
3. 从开始菜单或可选的桌面快捷方式启动。

静默安装：`BitstreamInspector-0.2.0-win64-setup.exe /S`
自定义目录：在最后添加 `/D=C:\path`（路径不要带空格）。

在 **设置 → 应用 → 已安装的应用 → Bitstream Inspector** 中卸载。卸载器可以
保留或删除 `%APPDATA%\BitstreamInspector` 中的设置。

## 验证

- 8 条 H.264/H.265 码流的帧数和 I/P/B 类型与 `ffprobe` 一致。
- SPS/PPS/slice 字段与 FFmpeg `trace_headers` 一致。
- 真实 MP4/TS/MKV（H.264/H.265）的解码帧与 FFmpeg 参考帧 PSNR = inf
  （逐像素一致）。
- ASan/UBSan 跑完测试集并通过 300 轮变异 fuzz。
- 安装器：静默安装、启动已安装程序、静默卸载，以及快捷方式和卸载注册表项
  均验证通过。

## 已知限制

- 裸流没有时间戳，画面页显示最近的关键帧（带标注），不是精确目标帧。
- 还没有缩略图条、slice/CTU 覆盖层、DPB/GOP 图、HRD/CPB 分析和宏块级熵解码。
- 每次解码是单线程的。
- 容器输入的 `偏移` 列是重构后的 Annex B 流内偏移，不是容器文件偏移。
- 安装包没有签名；首次运行 SmartScreen 可能提示确认。
