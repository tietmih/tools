# Bitstream Inspector 0.3.1

[English](v0.3.1.md) | 简体中文

Windows 10/11 x86-64，按用户安装，不需要管理员权限。

## 新增内容

- **自动化 CI/CD**。每次推送和拉取请求都会运行 Linux 解析/解码回归套件、
  ASan/UBSan 与变异 fuzz、Windows 界面和安装包的交叉构建，以及包含安装/卸载
  往返的原生 Windows 冒烟测试。推送 `bitstream-inspector-v<version>` tag 后，
  这些检查全部通过时自动发布本版本。
- **纳入版本库的测试**。`tests/unit_tests.cpp` 覆盖位读取器、RBSP 去防竞争、
  NAL 切分以及 H.264/H.265 参数集和 slice 头解析。脚本化套件用 FFmpeg 现场
  生成码流，并与 `ffprobe` 比较帧数和类型、与 FFmpeg `trace_headers` 比较语法
  字段、与 FFmpeg 逐像素比较解码帧。
- **FFmpeg 9.1**。内置 LGPL FFmpeg 从 7.1.5 升级到 9.1。媒体层已针对新头文件
  编译和测试；`AVFrame::pkt_pos` 回退逻辑按版本保护 FFmpeg 8+。
- **扩展 CI/CD**。Linux x64/arm64 回归、MSVC 构建、覆盖率、Windows GUI/安装器
  冒烟测试、便携 ZIP、发布 dry-run 开关，以及固定到 commit SHA 的 GitHub
  Actions。
- **依赖跟踪**。内置 FFmpeg 的版本和 SHA-256 固定在 `ci/deps.env`；每周工作流
  与上游稳定版比较，有新版本时创建跟踪 issue。Dependabot 负责更新 GitHub
  Actions 版本。
- **H.264 POC 回绕修复**。对于 `pic_order_cnt_type` 1 和 2，`FrameNumOffset`
  现在会在同一个 IDR 周期内跨 `frame_num` 回绕累加。此前 POC 在第二次回绕后
  重复先前的值，导致长 GOP 的显示顺序错乱。

## 安装

1. 下载 `BitstreamInspector-0.3.1-win64-setup.exe`（或便携版
   `BitstreamInspector-0.3.1-win64-portable.zip`）。
2. 运行安装包。按用户安装到
   `%LOCALAPPDATA%\Programs\BitstreamInspector`，不需要管理员权限或 UAC。
   便携 ZIP 解压到任意目录即可运行。
3. 从开始菜单或可选的桌面快捷方式启动程序。
4. 随时通过 **语言 / Language** 菜单切换界面语言。

静默安装：`BitstreamInspector-0.3.1-win64-setup.exe /S`
自定义目录：在最后添加 `/D=C:\path`（路径不要带空格）。

在 **设置 → 应用 → 已安装的应用 → Bitstream Inspector** 中卸载。卸载器会询问
是否保留 `%APPDATA%\BitstreamInspector` 中的设置。

## 验证

发布本版本要求以下任务全部通过：

- Linux x64/arm64：单元测试；8 个 H.264/H.265 码流（Baseline、Main、
  High 4:2:2、多 slice、长 GOP、Main10）的帧数和图像类型与 `ffprobe` 一致；
  语法字段与 FFmpeg `trace_headers` 一致；MP4/TS/MKV 的解码帧与 FFmpeg 逐像素
  一致；ASan/UBSan 无问题；固定种子的变异 fuzz 通过。测试链接的是与 Windows
  安装包相同的 FFmpeg 9.1 构建。
- MSVC：界面、命令行工具和单元测试编译通过，单元测试通过。
- Windows：交叉构建界面、命令行工具、安装包和便携 ZIP；在原生 Windows 上运行
  `bsinfo.exe`/`mtest.exe`；GUI 启动和运行时语言切换；便携 ZIP 解压运行；静默
  安装、检查版本资源、快捷方式和注册表、运行已安装的 `bsinfo.exe`、静默卸载。
- 覆盖率：插桩构建运行整套测试并上传报告。

## 已知限制

- 裸流没有时间戳，画面页显示最近的关键帧（带标注），不是精确目标帧。
- 还没有缩略图条、slice/CTU 覆盖层、DPB/GOP 图、HRD/CPB 分析和宏块级熵解码。
- 每次解码是单线程的。
- 容器输入的 `偏移` 列是重构后的 Annex B 流内偏移，不是容器文件偏移。
- 安装包没有签名；首次运行 SmartScreen 可能提示确认。
