# Bitstream Inspector 0.3.1

English | [简体中文](v0.3.1.zh-CN.md)

Windows 10/11 x86-64, per-user installer, no administrator rights required.

## What's new

- **Automated CI/CD**. Every push and pull request now runs the parser and
  decoder regression suite on Linux, an ASan/UBSan pass with mutation fuzzing,
  a Windows cross-build of the GUI and installer, and a native Windows smoke
  test including an installer round trip. Pushing a
  `bitstream-inspector-v<version>` tag publishes this release automatically
  once those checks pass.
- **Checked-in tests**. `tests/unit_tests.cpp` covers the bit reader, RBSP
  unescaping, NAL splitting and H.264/H.265 parameter-set and slice-header
  parsing. The scripted suite generates its own streams with FFmpeg and checks
  frame counts/types against `ffprobe`, syntax fields against FFmpeg
  `trace_headers`, and decoded frames against FFmpeg pixel by pixel.
- **FFmpeg 9.1**. The bundled LGPL FFmpeg build moves from 7.1.5 to 9.1.
  The media layer was compiled and tested against the new headers; the
  `AVFrame::pkt_pos` fallback is version-guarded for FFmpeg 8+.
- **Expanded CI/CD**. Linux x64 and arm64 regression tests, MSVC build,
  coverage, Windows GUI/installer smoke tests, a portable ZIP asset, a
  release dry-run switch and SHA-pinned GitHub Actions.
- **Dependency tracking**. The bundled FFmpeg version and its SHA-256 are
  pinned in `ci/deps.env`; a weekly workflow compares them with upstream
  stable releases and opens a tracking issue when an update is available.
  Dependabot keeps the GitHub Actions versions current.
- **H.264 POC wrap-around fix**. For `pic_order_cnt_type` 1 and 2,
  `FrameNumOffset` is now accumulated across `frame_num` wrap-arounds inside
  one IDR period. Previously POC repeated earlier values after the second
  wrap, shifting the presentation order of long GOPs.

## Install

1. Download `BitstreamInspector-0.3.1-win64-setup.exe` (or the portable
   `BitstreamInspector-0.3.1-win64-portable.zip`).
2. Run the installer. It is per-user, installs to
   `%LOCALAPPDATA%\Programs\BitstreamInspector` and needs no admin/UAC. The
   portable ZIP can be extracted anywhere.
3. Start the application from the Start Menu or the optional desktop shortcut.
4. Switch the application language from **Language / 语言** at any time.

Silent install: `BitstreamInspector-0.3.1-win64-setup.exe /S`
Custom directory: add `/D=C:\path` as the last argument (path without spaces).

Uninstall from **Settings → Apps → Installed apps → Bitstream Inspector**.
The uninstaller asks whether to keep `%APPDATA%\BitstreamInspector` settings.

## Verification

Publishing this release required the following jobs to pass:

- Linux x64 and arm64: unit tests; frame counts and picture types identical
  to `ffprobe` on eight H.264/H.265 streams (Baseline, Main, High 4:2:2,
  multi-slice, long GOP, Main10); syntax fields identical to FFmpeg
  `trace_headers`; decoded frames pixel-identical to FFmpeg on MP4/TS/MKV;
  ASan/UBSan clean; mutation fuzz with a fixed seed. The tests link the same
  FFmpeg 9.1 build that ships in the Windows package.
- MSVC: GUI, CLI and unit tests compile and the unit tests pass.
- Windows: cross-build of the GUI, CLI, installer and portable ZIP; native
  execution of `bsinfo.exe` and `mtest.exe`; GUI startup and runtime language
  switching; portable ZIP extraction; silent install, version-resource check,
  shortcuts and registry entries, running the installed `bsinfo.exe`, and
  silent uninstall.
- Coverage: the instrumented build runs the suite and uploads the report.

## Known limitations

- Raw elementary streams carry no timestamps; the Video tab shows the nearest
  keyframe (labelled) instead of the exact frame.
- No thumbnail strip, slice/CTU overlays, DPB/GOP graph, HRD/CPB analysis or
  macroblock-level entropy decoding yet.
- Decoding is single-threaded per request.
- Container inputs report `Offset` in the reconstructed Annex B stream, not in
  the container file.
- The installer is unsigned; SmartScreen may ask for confirmation on first run.
