# Bitstream Inspector 0.3.0

[English](v0.3.0.md) | 简体中文

双语版本。Windows 10/11 x86-64，按用户安装，不需要管理员权限。

## 新增内容

- **双语界面**：通过“语言 / Language”菜单在运行时切换英文和简体中文。选择保存在
  `%APPDATA%\BitstreamInspector\settings.ini`，下次启动自动恢复。标准术语
  （NAL 类型、SPS/PPS/VPS、语法字段名、编码/profile 名称）在两种界面语言下都
  保持英文。
- **双语文档**：README、更新日志、截图说明和发布说明均提供英文和简体中文两个
  版本，文件顶部带切换链接。
- **双语安装器**：NSIS 安装器启动时提供英文/简体中文选择，页面会本地化，并安装
  两种语言的 README 和 FFmpeg 构建信息。许可证页包含英文法律原文和中文说明。
- 帧列表列宽适配中文标题。
- PrintWindow 提供的 DC 没有兼容位图时，图表和十六进制视图直接绘制到目标 DC。

## 安装

1. 下载 `BitstreamInspector-0.3.0-win64-setup.exe`。
2. 运行安装包。按用户安装到
   `%LOCALAPPDATA%\Programs\BitstreamInspector`，不需要管理员权限或 UAC。
3. 选择安装器语言，然后从开始菜单或可选的桌面快捷方式启动。
4. 随时通过 **语言 / Language** 菜单切换程序界面语言。

静默安装：`BitstreamInspector-0.3.0-win64-setup.exe /S`
自定义目录：在最后添加 `/D=C:\path`（路径不要带空格）。

在 **设置 → 应用 → 已安装的应用 → Bitstream Inspector** 中卸载。卸载器会询问
是否保留 `%APPDATA%\BitstreamInspector` 中的设置。

## 验证

- 在 Windows 上验证了中英文运行时切换及重启后保持。
- 安装器：静默安装、启动已安装程序、静默卸载，以及快捷方式和卸载注册表项均
  验证通过。安装后的文件包含两种语言的 README 和 FFmpeg 构建信息。
- 解析/解码回归保持通过：帧数和类型 vs `ffprobe`；字段 vs FFmpeg
  `trace_headers`；真实 MP4/TS/MKV 的 PSNR = inf；ASan/UBSan 与变异 fuzz。
- 两种界面语言的字符串均已检查，中文标题的列宽已调整。

## 已知限制

- 裸流没有时间戳，画面页显示最近的关键帧（带标注），不是精确目标帧。
- 还没有缩略图条、slice/CTU 覆盖层、DPB/GOP 图、HRD/CPB 分析和宏块级熵解码。
- 每次解码是单线程的。
- 容器输入的 `偏移` 列是重构后的 Annex B 流内偏移，不是容器文件偏移。
- 安装包没有签名；首次运行 SmartScreen 可能提示确认。
