# Bitstream Inspector 0.2.0

First packaged release. Windows 10/11 x86-64, per-user installer, no
administrator rights required.

## Highlights

- H.264/H.265 analyzer with frame list, syntax tree, hex view, bitrate chart
  and decoded frame preview.
- Annex B elementary streams **and** MP4/MOV, MPEG-TS/M2TS, Matroska/WebM
  containers.
- Exact-frame video preview for containers (PTS-matched), background decoding,
  Hex/Video tabs.
- Draggable splitters, keyframe navigation, CSV export and persisted layout.
- Application icon and 0.2.0 version metadata.

## Install

1. Download `BitstreamInspector-0.2.0-win64-setup.exe`.
2. Run it. The installer is per-user, installs to
   `%LOCALAPPDATA%\Programs\BitstreamInspector` and needs no admin/UAC.
3. Start it from the Start Menu or the optional desktop shortcut.

Silent install: `BitstreamInspector-0.2.0-win64-setup.exe /S`
Custom directory: add `/D=C:\path` as the last argument (path without spaces).

Uninstall from **Settings → Apps → Installed apps → Bitstream Inspector**.
The uninstaller can keep or remove `%APPDATA%\BitstreamInspector` settings.

## Verification

- Frame counts and I/P/B types match `ffprobe` on eight H.264/H.265 streams.
- SPS/PPS/slice fields match FFmpeg `trace_headers`.
- Decoded frames are pixel-identical (PSNR = inf) to FFmpeg reference frames for
  real MP4/TS/MKV inputs, H.264 and H.265.
- ASan/UBSan clean over the test corpus plus 300 mutation-fuzz iterations.
- Installer: silent install, launch of the installed app and silent uninstall
  verified, including shortcuts and the uninstall-registry entry.

## Known limitations

- Raw elementary streams carry no timestamps; the Video tab shows the nearest
  keyframe (labelled) instead of the exact frame.
- No thumbnail strip, slice/CTU overlays, DPB/GOP graph, HRD/CPB analysis or
  macroblock-level entropy decoding yet.
- Decoding is single-threaded per request.
- Container inputs report `Offset` in the reconstructed Annex B stream, not in
  the container file.
- The installer is unsigned; SmartScreen may ask for confirmation on first run.
